## OpenLobbying

This repository contains the OpenLobbying application:

- dataset crawlers under `datasets/`
- the FastAPI API under `src/openlobbying/api/`
- the Svelte frontend under `src/`

Use `uv run` for Python commands and prefer running `muckrake` from this repo so dataset discovery and env loading use the OpenLobbying checkout by default.

Setup and the Quickstart are in `README.md`; `scripts/quickstart.sh` is the same Quickstart as a script, which `.github/workflows/quickstart.yml` runs on pull requests into `develop` and `main`. The API endpoint list is `docs/api.md`, generated by `uv run python scripts/gen_api_docs.py`; regenerate it after changing a route.

## OpenLobbying frontend

### Svelte MCP server

These instructions apply when the Svelte MCP server is configured in your agent (this repo doesn't configure it). It serves the Svelte 5 and SvelteKit documentation through four tools:

- `list-sections` lists the documentation sections, with titles, use cases and paths. Call it first for any Svelte or SvelteKit question.
- `get-documentation` returns the content of one or more sections. Use the `use_cases` field from `list-sections` to pick every section relevant to the task, and fetch them.
- `svelte-autofixer` checks Svelte code and returns issues and suggestions. Run it on Svelte code you write, and repeat until it reports nothing.
- `playground-link` creates a Svelte Playground link for code. Offer it only for code that was not written to files in this project, and call it only after the user agrees.

### Type safety

- TypeScript strict mode is enabled.
- Define interfaces for all data structures (see `src/lib/types.ts`).
- FtM entity properties are typed `Record<string, any[]>`, because property values vary by schema. Elsewhere, use specific types instead of `any`.

### Imports
- Use SvelteKit's `$lib` path alias for library imports
- Example:
  ```typescript
  import Properties from "$lib/components/Properties.svelte";
  import type { Entity } from "$lib/types";
  ```

### Svelte 5 runes
- Use `$props()` for component props
- Use `$derived` for computed values
- Use `$derived.by()` for complex derivations
- Example:
  ```svelte
  let { data } = $props();
  let entity = $derived(data.entity);
  ```

### Data fetching
- Use SvelteKit's `+page.ts` for data loading
- Fetch from FastAPI backend at runtime

### shadcn-svelte

Use `shadcn-svelte` components throughout the app for consistent styling. [Fetch the docs](https://www.shadcn-svelte.com/llms.txt) for usage examples.
