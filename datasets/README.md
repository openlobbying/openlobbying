# Dataset backlog

Dataset ideas are tracked as issues in this repo on [project board 1 ("Datasets")](https://github.com/orgs/openlobbying/projects/1). The IfG Ministers Database and IPSA's MP staffing and business costs are already there.

Sources noted here that have no issue yet:

- [Autonomy Data Unit post, 28 June 2024](https://adu.autonomy.work/posts/2024_06_28_reform/)
- [Violation Tracker UK](https://violationtrackeruk.goodjobsfirst.org/parent/alphabet-inc) (Good Jobs First): corporate penalties by parent company.
- Charities: [Find that Charity](https://findthatcharity.uk/about) ([source](https://github.com/kanedata/find-that-charity)) and the [UK Charity Classification](https://charityclassification.org.uk/).
- [gov-id-finder](https://gov-id-finder.codeforiati.org/) (Code for IATI): identifiers for government bodies.
